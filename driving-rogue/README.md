# Driving Rogue - Türkçe Yama

Oyunun **Türkçe yaması**: arayüz, menüler, tutorial, kartlar, araçlar ve tüm metinler Türkçe.

- Çevirmen: **mertpivvo**
- Sürüm: v2 (22.09.2026)
- Durum: ✅ 2.582 metin
- Tür: Arcade roguelike yarış
- Steam: https://store.steampowered.com/app/3088700/
- Yöntem: BepInEx 6 (IL2CPP) + XUnity.AutoTranslator, orijinal dosyalar değişmez

## Kurulum

1. `Driving-Rogue-TR-v2.zip` dosyasını açın.
2. İçindekileri (`BepInEx`, `dotnet`, `winhttp.dll`, `doorstop_config.ini`) oyunun kurulu olduğu klasöre kopyalayın (`Driving Rogue.exe` dosyasının yanına).
3. Daha önce eski sürüm yama kurduysanız oyun klasöründeki `BepInEx\cache` klasörünü silin.
4. Oyunu başlatın. Ayarlar menüsünde `Ayarlar - mertpivvo` imzasını göreceksiniz.
