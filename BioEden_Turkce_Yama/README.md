# BioEden Türkçe Yama

BioEden 1.2.0 için hazırlanmış, XUnity AutoTranslator/ReiPatcher tabanlı Türkçe arayüz ve oyun metni yamasıdır. Paket 3.752 kaynak metin için sözlük girdisi içerir. Çeviri imzası oyunun Yapım Ekibi ekranındaki Özel Teşekkürler bölümünde `mertpivvo` olarak görünür.

Kurulum ve kaldırma adımları `BENIOKU.txt` içindedir. ZIP içeriğini oyunun `BioEden.exe` dosyasının yanına çıkarıp `YamayiBaslat.bat` dosyasını çalıştır. ReiPatcher, özgün Unity kitaplığını tarihli `.bak` dosyasıyla korur.

Türkçe yama dosyaları `AutoTranslator/Translation/tr/Text/` altındadır. Orijinal oyun metin tabloları değiştirilmez.
