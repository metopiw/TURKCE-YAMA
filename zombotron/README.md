# Zombotron - Türkçe Yama

Oyunun **Türkçe yaması**: ana menü, ayarlar, kayıt ekranı, envanter, tüm hikaye diyalogları ve silah/eşya açıklamaları Türkçe.

- Çevirmen: **mertpivvo**
- Sürüm: v1.2 (23.09.2026) — v1.0/v1.1 üzerine kurulur
- v1.2 düzeltmesi: diyaloglarda görünmeyen ı, ş, ğ, İ, Ğ, Ş harfleri için 5 fontun (Akashi 14/16/18/20/24) atlas dokusuna eksik 6 glif işlendi; `resources.assets.resS` de yamaya eklendi
- Durum: ✅ 1110 metin
- Tür: 2D aksiyon-platform
- Steam: https://store.steampowered.com/app/664830/Zombotron
- Yöntem: dosya değişimli (`Zombotron_Data\resources.assets` Türkçeye çevrilmiş sürümle değişir, İngilizce metinlerin üzerine yazılır)

## Kurulum

1. `Zombotron_Turkce_Yama_v1.2.zip` dosyasını açın.
2. `Zombotron_Data` içindeki `resources.assets` ve `resources.assets.resS` dosyalarının yedeğini alın.
3. Yamadaki iki dosyayı `Zombotron_Data` içine kopyalayın, üzerine yazın.
4. Oyun açıksa tamamen kapatıp yeniden açın. Dil İngilizce kalsın. Yazılar Türkçe görünür.
